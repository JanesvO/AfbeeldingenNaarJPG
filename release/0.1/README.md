# Afbeeldingen Naar JPG release 0.1

Deze release is bedoeld voor gebruik op andere Windows-pc's zonder aparte Python-installatie.

## Wat is nodig op de andere pc
- Windows 10 of 11
- geen Python nodig
- geen handmatige package-installatie nodig
- geen extra software nodig naast wat in deze release zit

## Aanbevolen installatie
Open:

`Install-AfbeeldingenNaarJPG-Standalone.cmd`

Dit script:
- kopieert het programma naar `%LOCALAPPDATA%\Programs\AfbeeldingenNaarJPG`
- maakt een bureaublad-snelkoppeling
- maakt een snelkoppeling in het startmenu

## Direct starten zonder installatie
Dat kan ook via:

`Start-AfbeeldingenNaarJPG.cmd`

of rechtstreeks via:

`standalone\AfbeeldingenNaarJPG\AfbeeldingenNaarJPG.exe`
